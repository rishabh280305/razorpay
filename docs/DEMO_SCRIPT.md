# Judge demo — five minutes

**0:00–0:30 — Problem.** “AI can recommend products, but merchants cannot allow an unbounded agent to spend or alter an order. AgentReady makes a Razorpay merchant AI-buyable without surrendering authority.”

**0:30–1:00 — Command Center.** Point out the test-mode banner and synthetic labels. “We never present benchmark money as real revenue.”

**1:00–2:20 — Golden path.** Open Buyer Agent, use sensitive-skin prompt, show parsed budget/fragrance constraints, the Growth recommendation, the authoritative total, and human approval threshold. Approve mandate and explain that only the server can create the TEST Order.

**2:20–3:05 — Safety proof.** Open Policies then Audit Trail. “AI proposes; deterministic code re-reads price/inventory, authorizes, and hash-links the evidence.”

**3:05–3:40 — Failure.** Run Chaos Lab. “Price changes after approval; total crosses the mandate. The order is blocked before Razorpay.”

**3:40–4:20 — Interoperability.** Open Protocol Lab, catalog JSON feed and ACP lifecycle. “ACP/MCP are adapters to the same policy core; AP2 is accurately labeled as conceptual compatibility.”

**4:20–4:45 — Growth evidence.** Show Growth Eval: 500 fixed-seed sessions, +12.8% simulated GMV, zero policy violations.

**4:45–5:00 — Why Razorpay.** “Razorpay remains the payment rail. AgentReady gives it merchant-ready agent commerce: bounded intent, legitimate authority, webhook-confirmed finality and an audit story.”
